# NecroBug


## File Structure

- Assets: overarching folder where the games assets are stored. Things such as scripts and models. 
	- Scripts: files and subfolders containing the C# scripts used in the project. subfolders contain scripts organized by purpose
	- ArtAssets: the files and subfolders contain the materials, UI assets, prefabs and other art assets. subfolders are organized by type and use case.
	- Misc: files that don't fit into the main categories. typically from various package imports.  
	- Scenes: Scene files and other requires files for the projects scenes
- Packages: json files for installed packages
- ProjectSettings: Untiy files for the settings for the project
